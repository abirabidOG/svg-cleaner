Clean the given SVG file or files using the svg-cleaner skill.

Use the svg-cleaner skill to clean `$ARGUMENTS` to smaller, cleaner SVG
files, locally, with the bundled SVGO script. Report the output file, input
and output sizes, and the saving for each file. Never quote a saving
percentage you did not measure.
